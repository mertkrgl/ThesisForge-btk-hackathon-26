# Brand Logoları

`DataSources.tsx` bileşeni bu klasörden 4 SVG bekler:

- `kap.svg`  — Kamuyu Aydınlatma Platformu (kap.org.tr)
- `bist.svg` — Borsa İstanbul (borsaistanbul.com)
- `tcmb.svg` — Türkiye Cumhuriyet Merkez Bankası (tcmb.gov.tr)
- `mkk.svg`  — Merkezi Kayıt Kuruluşu (mkk.com.tr)

Resmi sitelerden veya basın kitlerinden indirip bu klasöre `kap.svg`, `bist.svg`, `tcmb.svg`, `mkk.svg` adlarıyla yerleştirin. Görseller kartlarda beyaz zemin üzerinde 44×44 alanda `object-contain` ile gösterilir; bu yüzden şeffaf zeminli SVG/PNG idealdir.

Logo kullanımı ilgili kurumların marka politikasına tabidir; kullanım izni proje sahibinin sorumluluğundadır.
