# Marka ve Kütüphane Logoları

`TrustedBy.tsx` ve `DataSources.tsx` bileşenleri logoları bu klasörden okur.

Mevcut veri kaynağı logoları:

- `kap-logo.jpeg` — Kamuyu Aydınlatma Platformu (kap.org.tr)
- `borsa-istanbul-logo.png` — Borsa İstanbul (borsaistanbul.com)
- `TCMB_logo.svg` — Türkiye Cumhuriyet Merkez Bankası (tcmb.gov.tr)
- `MKK-EN-Dikey-Logo-Siyah.png` — Merkezi Kayıt Kuruluşu (mkk.com.tr)

Kullanılan kütüphaneler satırı için beklenen dosyalar:

- `strands-logo-black.svg` — Strands Agents light tema
- `logo-header-dark.LyjuOEMF.svg` — Strands Agents dark tema
- `yfinance-logo.webp` — yfinance light tema
- `yfinance-white.webp` — yfinance dark tema
- `gemini-logo.svg` — Gemini
- `pandas_ta-logo.webp` — pandas-ta

Bu logolar `frontend/public/logos/` klasöründen okunur. Dosya adı veya uzantı değişirse `TrustedBy.tsx` içindeki `LIBRARY_LOGOS` yollarını aynı şekilde güncelleyin.

Logo kullanımı ilgili kurumların marka politikasına tabidir; kullanım izni proje sahibinin sorumluluğundadır.
